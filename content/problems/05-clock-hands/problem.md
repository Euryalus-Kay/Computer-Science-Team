An analog clock shows a time given in 24-hour format. The hour hand moves smoothly: at 3:30 it is halfway between 3 and 4.

Find the smaller angle between the two hands, in degrees.

## Input
The first line contains `t` (1 ≤ t ≤ 1440). Each of the next `t` lines contains a time `HH:MM` with 00 ≤ HH ≤ 23 and 00 ≤ MM ≤ 59.

## Output
For each time print the angle with exactly one digit after the decimal point.
