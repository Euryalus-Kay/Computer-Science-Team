---
title: Running Total
difficulty: easy
tags: arrays, warm-up
---
Numbers arrive one at a time. After each one, report the total so far.

## Input
The first line contains `n` (1 ≤ n ≤ 10⁵). The second line contains `n` integers, each between −10⁹ and 10⁹.

## Output
Print `n` integers on one line, separated by spaces: the running totals.
