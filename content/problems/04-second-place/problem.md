title: Second Place
difficulty: easy
tags: arrays
---
Given everyone's score, find the second highest **distinct** score. Ties for first place do not count as second place.

## Input
The first line contains `n` (1 ≤ n ≤ 10⁵). The second line contains `n` integers between 0 and 10⁹.

## Output
Print the second highest distinct score, or `NONE` if every score is the same.
