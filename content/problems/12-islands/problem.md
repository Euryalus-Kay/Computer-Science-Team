A map is a grid of land `#` and water `.`. Land cells that touch horizontally or vertically belong to the same island. Diagonal touching does not count.

Count the islands.

## Input
The first line contains `r` and `c` (1 ≤ r, c ≤ 500). Each of the next `r` lines has `c` characters.

## Output
Print the number of islands.
