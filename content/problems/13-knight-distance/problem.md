A chess knight moves two squares in one direction and one square perpendicular to it. On an `n × n` board, find the fewest knight moves from one square to another.

## Input
The first line contains `t` (1 ≤ t ≤ 20). Each of the next `t` lines contains `n r1 c1 r2 c2` (1 ≤ n ≤ 300, 1 ≤ r, c ≤ n).

## Output
For each line print the minimum number of moves, or `-1` if the target cannot be reached.
