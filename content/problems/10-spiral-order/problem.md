difficulty: medium

Read a grid of numbers in a clockwise spiral: along the top row, down the right column, back along the bottom row, up the left column, then continue inward.

## Input
The first line contains `r` and `c` (1 ≤ r, c ≤ 100). Each of the next `r` lines has `c` integers.

## Output
Print all `r · c` numbers in spiral order on one line, separated by spaces.
